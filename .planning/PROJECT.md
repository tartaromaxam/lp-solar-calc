# Projeto: Solar Pro (Mavinic)

Ecossistema de geração de leads de alta conversão para energia solar, focado no domínio `solar.mavinic.com.br`.

## Visão Geral
Criar uma experiência premium que combine uma Landing Page de alto impacto com um widget de calculadora solar sofisticado para capturar leads qualificados.

## Objetivos Principais
- **Conversão**: Capturar leads através de simulações em tempo real.
- **Tecnologia**: Utilizar Next.js 15 para performance e SEO.
- **Automação Comercial (V2.1)**: Notificar a equipe de vendas via WhatsApp utilizando a Evolution API com a análise do lead e links pré-preenchidos (`wa.me`) para homologação de pitches de vendas.
- **Portabilidade**: Manter o widget (`spc-widget.js`) como um componente portátil.
- **Automação**: Integrar com Make.com e Google Sheets para processamento operacional de dados.

## Stack Técnica
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Animações**: Framer Motion
- **Backend/Automation**: Make.com (Webhooks), Google Sheets
- **IA/Language Model**: Gemini (via OpenRouter)
- **Mensageria/WhatsApp**: Evolution API
- **Deployment**: Vercel
- **Tracking**: GTM / DataLayer
