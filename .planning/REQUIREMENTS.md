# Requisitos: Solar Pro (Mavinic)

## 1. UI/UX (Landing Page)
- [ ] Design premium com suporte a Dark Mode e Glassmorphism.
- [ ] Seções: Hero, Benefícios, Pain (Dores), Projetos, Footer.
- [ ] Otimização de Performance (Lighthouse > 90).
- [ ] Responsividade total (Mobile First).

## 2. Calculadora (Widget)
- [ ] Lógica de cálculo baseada em tarifas regionais (configurável).
- [ ] Animações suaves nos resultados (Savings, Payback, System Size).
- [ ] Proteção contra Hydration Errors no Next.js.
- [ ] Fallback visual para falhas de rede.

## 3. Captura e Integração de Leads
- [ ] Envio simultâneo para Make.com e Railway.
- [ ] Captura de metadados (UTMs, dispositivo, origem).
- [ ] Botão de WhatsApp com mensagem dinâmica baseada na simulação.
- [ ] Sistema de retry para falhas de envio de webhook.

## 4. Tracking & Analytics
- [ ] Implementação de DataLayer para eventos de simulação.
- [ ] Tracking de cliques no WhatsApp e conversões de formulário.
