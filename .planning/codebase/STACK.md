# Tech Stack - Solar Energy LP

## Core
- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript 5.x
- **Runtime**: Node.js (Vercel Deployment)

## Styling
- **CSS**: Tailwind CSS 4.x
- **Icons**: Lucide React
- **Animations**: Framer Motion

## Backend & Integration
- **Leads Storage**: Google Sheets (via `google-spreadsheet` and `google-auth-library`)
- **Webhooks**: Make.com, Railway (Telegram Bot)
- **Environment**: Dotenv for local configuration

## Tooling
- **Linting**: ESLint 9.x
- **Build**: Next.js optimized build (`out` directory indicates static export potential)
